# 05 원고 · NETWORK · PARTNERS · 상담 · LEGAL

## NETWORK

### 01 HERO

- **영문** Network
- **제목** 전국 주요 거점의 협력 의료기관을, 같은 기준으로 연결합니다
- **본문** 서울 강남, 인천 송도·검단, 경기 용인, 대구, 부산의 협력 의료기관과 함께합니다. 의료기관의 이름과 정확한 주소는 공개하지 않으며, 상담에서 목적에 맞는 기관을 개별로 안내합니다.
- **그래픽** 실제 행정구역 데이터로 그린 한국 지도 + 거점 표시, 수도권 확대 지도

### 02 지도와 분야 필터

- **필터** 전체 / 건강검진 / 재생의료·줄기세포 / 성형·피부 / 여성건강 / 남성건강 / 한방·웰니스
- **동작** 분야를 고르면 그 분야를 연결하는 거점만 진하게 표시하고 나머지는 흐리게 둡니다. 연결 거점이 없는 분야를 고르면 "이 분야는 상담을 통해 의료기관을 안내합니다" 문장을 보여줍니다.
- **거점 카드** 지도 아래에 같은 필터가 적용된 카드 목록을 둡니다. 모바일에서는 지도 대신 카드 목록이 먼저 보입니다.
- **데이터** 관리시트의 '거점' 탭에서 읽습니다. (아래 05)

### 05 관리시트 연동

시트 파일을 두 개로 나눕니다. **공개용 시트**만 웹에 게시하고 사이트가 읽습니다. **내부 시트**에는 기관명·주소·계약 정보를 두고 절대 웹에 게시하지 않습니다. 웹 게시는 탭이 아니라 파일 단위로 노출될 수 있으므로 두 파일을 섞지 않습니다.

| 시트 · 탭 | 열 | 용도 |
| --- | --- | --- |
| 공개용 · 거점 | hub\_id / 지역 표시명 / 위도 / 경도 / 분야(쉼표 구분) / 카드 문장 / 사진 코드 / 공개(Y/N) / 정렬 | 지도 표시, 분야 필터, 거점 카드 |
| 공개용 · 분야 | cat\_id / 분야명 / 상담폼 미리선택 값 / 페이지 주소 | 필터 칩, 상담 버튼 링크 |
| 공개용 · 사진 | photo\_code / 페이지·블록 / 파일 주소 / 대체 텍스트 / 공개(Y/N) | 시설·상담실 사진 교체 |
| 내부 · 기관 | inst\_id / 정식 기관명 / 주소 / hub\_id / 분야 / 공식 사이트 / 계약 상태 / 기관명 공개 / 로고 공개 / 주소·핀 공개 / 자료 수령일 / 담당자 | 기관 관리, 향후 CMS 이전 |
| 내부 · 사진 원본 | photo\_code / 원본 파일 / 제공 기관 / 사용 허락(Y/N) / 병원명 노출 확인 / 검수자 | 사진 권리 관리 |

- **새 기관 추가 규칙** 내부 시트에 기관 한 줄 추가 → 공개용 '거점' 탭의 분야에 반영 → 사진은 사용 허락과 병원명 가림을 확인한 뒤 공개용 '사진' 탭에 추가. 사이트는 공개(Y) 행만 표시합니다.
- **가격 열** 만들지 않습니다.

### 03 Partner Standard \[기존\]

파트너의 이름보다, 고객 경험의 완성도를 봅니다.

1. **RESPONSE** — 상담과 일정 요청에 대한 응답 속도
2. **GLOBAL READINESS** — 외국인 고객 응대와 의료 커뮤니케이션
3. **TRANSPARENCY** — 의료비와 서비스 범위의 명확성
4. **VIP FLOW** — 프라이버시와 고객 동선을 고려한 운영
5. **CONTINUITY** — 결과 이후의 상담과 사후관리 연결 가능성

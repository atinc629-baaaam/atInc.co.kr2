# 06 사진 리스트

원고에 나온 사진 코드를 한곳에 모았습니다. 사진이 들어오면 코드로 파일 이름을 붙이고, 공개용 시트 '사진' 탭에 한 줄씩 넣으면 해당 블록의 임시 이미지가 교체됩니다.

## 촬영·선별 규칙

1. **병원명 가림** 간판, 벽면 로고, 유니폼 자수, 모니터 화면에 병원명이 보이면 촬영 각도를 바꾸거나 잘라냅니다.
2. **사람** 환자 얼굴은 쓰지 않습니다. 의료진·직원은 본인 동의가 있을 때만, 뒷모습이나 손 위주로 씁니다.
3. **금지** 수술 장면, 혈액·상처 등 자극적인 이미지, 시술 전후 비교 사진, 가격표가 보이는 사진
4. **권리** 계약기관 사진은 사용 허락을 서면(이메일 가능)으로 받고 내부 시트에 기록합니다.
5. **톤** 자연광, 밝은 아이보리·우드·브라운, 넓은 여백. 파란 조명과 형광등 느낌은 보정합니다.
6. **파일** 가로형은 긴 변 2400px 이상, 세로형은 1600px 이상. 파일명은 코드\_버전 (예: M1-01\_v1.jpg)
7. **스톡** 실제 자료가 없는 자리에만 임시로 쓰고, 실제 사진이 들어오면 바로 교체합니다.

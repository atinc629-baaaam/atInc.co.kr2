# atInc 홈페이지 (정적 사이트)

HTML·CSS·JS만으로 된 19페이지 사이트입니다. 빌드 과정이 없어 이 폴더를 그대로 웹 호스팅에 올리면 됩니다. `index.html`이 첫 화면입니다.

## 올리는 방법
- 일반 웹호스팅(카페24·가비아 등): FTP로 폴더 안의 파일 전체를 웹 루트(`www` 또는 `public_html`)에 올립니다.
- 무료 정적 호스팅(Netlify·Cloudflare Pages·GitHub Pages): 폴더를 끌어다 놓으면 배포되고, 도메인 atinc.co.kr을 연결합니다.

## 바꾸는 곳
| 할 일 | 파일 | 방법 |
| --- | --- | --- |
| 상담 버튼 연결 | `assets/site.js` | `FORM_URL`에 기존 atinc.co.kr Google Form 주소가 들어 있습니다. 모든 상담 버튼이 이 폼을 새 탭으로 엽니다. |
| 관심 분야 미리 선택 | `assets/site.js` | 폼 편집 → 미리 채워진 링크 가져오기 → 관심 분야 문항의 `entry.숫자`를 `FORM_CATEGORY_ENTRY`에 적으면, 분야별 버튼이 해당 분야를 미리 선택합니다. |
| 회사 주소 | 각 HTML 푸터·ABOUT·Medical Notice | 주소가 정해지면 다시 생성하거나 해당 줄에 추가합니다. 지금은 주소 줄을 빼 두었습니다. |
| 개인정보처리방침 빈칸 | `privacy.html` | 노란 표시된 [기간], [이름·연락처], [시행일]을 채웁니다. |
| 협력 병원 추가·변경 | `assets/network-data.js` | 이 파일 하나만 고치면 됩니다. 한 줄에 병원 하나씩, 지역(예: `대전 유성구`)과 분야만 적으면 지도에 점이 찍히고 해당 구가 밝아지며, 목록·분야 필터·지역 문구가 모두 자동으로 바뀝니다. 같은 지역에 여러 곳이면 지도에서 한 점으로 묶이고 "외 n곳"으로 표시됩니다. 병원 이름은 적지 않습니다. |
| 공유 미리보기 이미지 | `assets/og.png` | 카카오톡·위챗으로 링크를 보낼 때 뜨는 1200×630 이미지입니다. 실제 사진이 생기면 같은 이름으로 바꿉니다. |
| 검색 등록 | `sitemap.xml`, `robots.txt` | 도메인을 연결한 뒤 네이버 서치어드바이저와 구글 서치 콘솔에 `https://atinc.co.kr/sitemap.xml`을 제출합니다. |
| WeChat·WhatsApp ID | 상담 블록의 해외 연락 줄 | ID가 정해지면 이메일·전화 옆에 추가합니다. 지금은 이메일과 +82 번호만 적어 두었습니다. |
| 움직이는 배경·유리 효과·3D 세포 | `assets/fx/` | 홈 첫 화면·프로그램·상담 영역과 분야·프로그램 페이지 상단의 움직이는 배경(ShaderGradient), 메뉴·회사 정보 띠·프로그램 카드·상담 패널의 유리 효과(liquid-glass-js 방식), 셀 케어 영역의 3D 세포(three.js)입니다. 웹서버(https)에 올렸을 때 동작하고, 파일을 더블클릭해 열거나 오래된 기기에서는 같은 색의 정지 배경과 세포 사진으로 대신 보입니다. 사용한 오픈소스와 라이선스는 `assets/fx/THIRD_PARTY_NOTICES.txt`에 있습니다. |
| 대표 소개 다시 보이기 | 빌드 스크립트 | 지금은 홈과 ABOUT에서 대표 소개 섹션을 숨겨 두었습니다. 다시 넣을 때 말씀해 주세요. |
| 사진 | `assets/img/` | 지금 두 장은 분위기 참고용 임시 이미지입니다. 분야 페이지 '공간과 경험'의 사진 자리는 `data-photo="M1-08a"`처럼 사진 코드가 붙어 있어 같은 코드의 실제 사진으로 바꾸면 됩니다. |

## 지킬 것
병원명·로고·정확한 주소, 가격, 허락받지 않은 사진·전후 사진은 사이트에 넣지 않습니다.

# 원고 · MEDICAL 인덱스

MEDICAL은 "무엇을 알아볼 수 있는가"를, atinc CARE는 "atinc가 어떻게 관리하는가"를 말합니다. 두 영역을 섞지 않습니다. 6개 분야 원고는 이 탭 아래 하위 탭에 있습니다.

### 인덱스 페이지 원고

- **작은 제목** MEDICAL
- **제목** 무엇을 알아볼 수 있는지부터 정리했습니다
- **본문** 분야마다 무엇인지, 어떤 종류가 있는지, 어떻게 진행되는지, 무엇을 확인해야 하는지 순서로 설명합니다. 실제 검사·진료·시술 여부와 방법은 의료진 상담을 통해 결정됩니다.

| 카드 | 설명 |
| --- | --- |
| 01 건강검진 | 연령·가족력·생활습관에 맞춰 검사 구성을 고르는 정밀검진. 결과 이후 전문의 연결까지 안내합니다. |
| 02 재생의료·줄기세포 | 자가 세포 보관부터 연구 기반 프리미엄 셀 케어 라인까지, 라인업과 진행 과정을 안내합니다. |
| 03 성형·피부 | 리프팅, 스킨부스터, 레이저, 성형수술의 종류와 진행 과정을 안내합니다. |
| 04 여성건강 | 갱년기·폐경, 골반저 질환, 여성 특화 검진을 프라이빗하게 상담합니다. |
| 05 남성건강 | 전립선·배뇨, 남성 갱년기, 남성 기능 등 비뇨의학과 상담을 연결합니다. |
| 06 한방·웰니스 | 침·약침·추나·한약 등 한의 진료와 한·양방 협진, 입원 회복 관리를 안내합니다. |

- **아래 안내** 어떤 수준으로 관리받을지는 atinc CARE에서 고를 수 있습니다. → atinc CARE
- **공통 고지** 이 페이지의 내용은 일반 안내입니다. 검사·진단·치료의 필요성과 방법은 의료기관과 담당 의료진이 판단하며, 결과는 개인에 따라 다를 수 있습니다.
